Throwaway architecture prototype

Keep the archive exact and the Pack semantic.

Drive acquisition, decoding, encoding, and publication independently. The demo exposes what survives each failure, where limits apply, and whether a retry needs another encoding pass.

Settled direction: use one owned, bounded exact-byte value, concrete persistence adapters, and thin open/save conveniences over the explicit phases. Limits use separate mandatory profiles, file replacement is atomic, and failed saves return encoded bytes. Decoding borrows non-cloneable bytes; conveniences cover filesystem paths and standard streams. Unknown members consume metadata limits only; atomicity makes no crash-durability promise.
