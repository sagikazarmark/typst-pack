Who decides what gets read?

This demo tests storage-owned project membership. Each source-specific gatherer chooses how to filter, prune, list, and read; the shared core receives exact selected entries only. Project Snapshot assembly then enforces universal invariants, not source policy. The awkward case is deliberate: a buggy over-inclusive gatherer can produce a larger but still valid Project Snapshot.
